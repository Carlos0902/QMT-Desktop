# QMT Desktop

Windows 10/11 x64 场外权益基金研究工具，包含基金分析、组合分析、回测、模型调参和供 AI 客户端调用的本地 MCP Server。

## 安装与使用

1. 从 [GitHub Releases](https://github.com/Carlos0902/QMT-Desktop/releases/latest) 下载并运行 x64 安装程序。安装在当前 Windows 用户目录，包含独立的 Python 运行环境。
2. 从开始菜单启动 QMT Desktop。首次启动会打开“设置”。填入自己的 Tushare Pro Key，点击“保存”。应用使用当前 Windows 用户的凭据管理器保存密钥，点击“清除”即可删除。
3. 在“基金分析”页点击“打开控制台”。输入六位场外基金代码并选择分析日期。可用范围受 Tushare 账号的权限、请求频率和基金数据覆盖影响。
4. 首次安装从空数据目录开始，基金市场数据按需下载至当前用户的本地应用数据目录。控制台的持仓表单由用户自行录入，保存在对应浏览器的本地存储中。

## 连接 AI 客户端

在桌面窗口的“设置”中点击“复制 AI 客户端配置”。在支持 MCP 的客户端新增本地 **stdio** 服务。支持 `mcpServers` JSON 的客户端可直接使用复制的配置，其他客户端分别填写其中的 `command` 和 `args`。命令使用安装目录中解释器的绝对路径。AI 客户端以同一 Windows 用户运行即可，桌面窗口可以关闭。

| 工具 | 功能 |
| --- | --- |
| `qmt_status` | 查看版本、数据源和 Key 配置状态 |
| `fund_nav` | 按基金代码与日期范围查询 Tushare 净值，单次最多一年 |
| `analyze_cached_fund` | 对已在控制台采集的基金执行指定日期的本地分析 |

示例提问：“检查 QMT 数据源状态，再查询基金 000001 从 2024-01-01 到 2024-01-31 的净值。”设置中保存新 Key 后，后续 MCP 请求会重新读取凭据。

## 研究与数据

排序研究和收益评测使用各自的数据范围、费用假设和时间条件。界面中的历史表现、预测区间和模拟结果均供研究参考。行情仅通过用户配置的数据源查询。基金当时可见的信息受净值公告与持仓披露日期约束。

## 构建

Windows x64 构建流程见 `.github/workflows/windows.yml`。使用含 Tcl/Tk 的 64 位 CPython 3.13、uv、.NET Framework C# 编译器和 Inno Setup 6。安装包包含应用代码、运行时及依赖。Windows 冒烟测试会在临时安装目录验证启动、凭据、控制台和 MCP 握手。
